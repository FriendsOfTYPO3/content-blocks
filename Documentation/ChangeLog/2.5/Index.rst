===
2.5
===

Content Blocks version 2.5 adds a collection of small new features.

..  contents::

Feature
=======

Title Field for Collection
--------------------------

An alternative :ref:`title <confval-collection-title>` for Collections is added.
This title field allows to overwrite the collection name in Record Permissions
view. It defaults to the collection label if empty.
